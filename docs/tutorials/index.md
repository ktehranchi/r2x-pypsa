# Tutorials

These tutorials will teach you the basics of using r2x-pypsa. They are designed to be followed in order, building on concepts from previous tutorials.

## Learning Path

1. **[Parsing PyPSA Networks](parsing-pypsa.md)** - Learn how to load and parse PyPSA networks into R2X System format
2. **[Converting to Sienna](converting-to-sienna.md)** - Learn how to convert R2X Systems to Sienna/PowerSystems.jl format

## Prerequisites

Before starting these tutorials, make sure you have:

- Installed r2x-pypsa ([Installation Guide](../installation.md))
- Basic familiarity with Python
- A PyPSA network file (NetCDF format) to work with

## Sample Data

The tutorials use sample data from the `tests/data/` directory. You can use the provided test networks or your own PyPSA networks.
